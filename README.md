# 星潮魔導姬 全息卡牌

即時繪製的 3D 全息卡牌，在瀏覽器裡用 WebGL2 著色器運算，不是影片。

線上觀看：https://arnoralex.github.io/holo-card-web/

## 操作

- 拖曳：旋轉卡片，視差與鐳射箔反光會跟著角度變化
- 滾輪或雙指：拉近拉遠
- Shift＋拖曳，或雙指拖曳：移動位置
- 在卡片上連按兩下：回到預設視角
- 右側面板：播放 15 秒展示與配樂、把七個圖層拉開、開關個別圖層

## 內容

- `index.html`：整個頁面（樣式與程式都內嵌）
- `assets/`：各圖層貼圖、卡背、配樂

需要支援 WebGL2 的瀏覽器（新版 Chrome、Edge、Safari、Firefox）。
